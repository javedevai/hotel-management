# Quetta A1 Hotel - Neon Nexus

A modern hotel management system with AI-powered concierge, built with React, TypeScript, Vite, and Supabase.

## Features

- 🏨 Room booking system
- 🍽️ In-room dining
- 🤖 AI-powered concierge
- 👥 User authentication
- 📊 Staff dashboard
- 🧹 Housekeeping management
- 👨‍🍳 Kitchen order management

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- Google Generative AI
- React Router
- Recharts

## Getting Started

```bash
npm install
npm run dev
```

## Database Setup

Run the SQL in `supabase-schema.sql` in your Supabase SQL Editor to create the required tables.
